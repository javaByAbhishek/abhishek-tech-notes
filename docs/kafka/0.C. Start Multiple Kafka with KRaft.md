# Kafka KRaft — 3 Broker Quick Start on Windows
### **1️⃣ Broker Configuration `config\kraft\server-1.properties`**
## Server 1

```
process.roles=broker,controller
node.id=1

### KRaft controller quorum - same on all servers
controller.quorum.voters=1@localhost:9093,2@localhost:9095,3@localhost:9097

# Broker port: 9092 | Controller port: 9093
listeners=PLAINTEXT://localhost:9092,CONTROLLER://localhost:9093

# Client connection address
advertised.listeners=PLAINTEXT://localhost:9092

# Listener protocol mapping
listener.security.protocol.map=PLAINTEXT:PLAINTEXT,CONTROLLER:PLAINTEXT

# Broker-to-broker communication
inter.broker.listener.name=PLAINTEXT

# KRaft controller communication
controller.listener.names=CONTROLLER

# Server 1 data directory
log.dirs=C:/kafka/data/server-1/kraft-combined-logs
```

| Server | Node ID | Broker Port | Controller Port |
| :--- | :--- | :--- | :--- |
| Server 1 | 1 | 9092 | 9093 |
| Server 2 | 2 | 9094 | 9095 |

The following configuration must be exactly the same on all three servers:

```text
controller.quorum.voters=1@localhost:9093,2@localhost:9095,3@localhost:9097
```

### 3. Create Data Directories

Open Command Prompt:

```cmd
cd C:\kafka
```

Create the directories:

```cmd
mkdir C:\kafka\data
mkdir C:\kafka\data\server-1
mkdir C:\kafka\data\server-2
mkdir C:\kafka\data\server-3
```

### 4. Generate KRaft Cluster ID
* **Key term:** Cluster ID
* **Important rule:** Generate the cluster ID only once and use the same ID for all three servers.
* **Example:** `4L6xJwXhQkKx8VvL9pQe7A`

Run:

```cmd
bin\windows\kafka-storage.bat random-uuid
```

Example output:

```text
4L6xJwXhQkKx8VvL9pQe7A
```

Save this value.

> ⚠️ **Important:** Use the same cluster ID for Server 1, Server 2, and Server 3.

### 5. Format Server 1
* **Key term:** Kafka storage format
* **Important rule:** Replace `YOUR_CLUSTER_ID` with the cluster ID generated in the previous step.
* **Example:** Use the same cluster ID for all three servers.

```cmd
cd C:\kafka\bin\windows
```
```cmd
kafka-storage.bat format -t YOUR_CLUSTER_ID -c C:\kafka\config\kraft\server-1.properties
```
Example:

```cmd
kafka-storage.bat format -t a_DSIh1HTFOCuTTDyeSpRw -c C:\kafka\config\kraft\server-1.properties
```

### 6. Format Server 2
* **Key term:** Server 2 storage format
* **Important rule:** Use the same cluster ID as Server 1.

```cmd
kafka-storage.bat format -t a_DSIh1HTFOCuTTDyeSpRw -c C:\kafka\config\kraft\server-2.properties
```


### 7. Format Server 3
* **Key term:** Server 3 storage format
* **Important rule:** Use the same cluster ID as Server 1 and Server 2.

```cmd
kafka-storage.bat format -t a_DSIh1HTFOCuTTDyeSpRw -c C:\kafka\config\kraft\server-3.properties
```

### 11. Verify KRaft Cluster
* **Key term:** KRaft controller quorum
* **Important rule:** The quorum should contain nodes 1, 2, and 3.
* **Example:** Check the quorum using Server 1 as the bootstrap server.

Open CMD Window 4:

```cmd
cd C:\kafka\bin\windows
```

Run:

```cmd
kafka-metadata-quorum.bat --bootstrap-server localhost:9092 describe --status
```

You should see the KRaft controller quorum containing:
```text
1
2
3
```

✅ **Create a topic**:
* **Key term:** Replication factor
* **Important rule:** A replication factor of 3 means each partition has three replicas.
* **Example:** Create `test-topic` with 3 partitions and 3 replicas.

```sh
kafka-topics.bat --create --topic product-created-events-topic --bootstrap-server localhost:9092 --partitions 3 --replication-factor 3
```

Expected output:
```text
Created topic test-topic.
```

✅ **Verify Topic**:
* **Key term:** Partition
* **Important rule:** All three brokers should participate in the replicas.
* **Example:** Each partition has replicas on brokers 1, 2, and 3.

Run:

```sh
kafka-topics.bat --describe --topic product-created-events-topic --bootstrap-server localhost:9092
```

Example output:
```text
Partition: 0    Leader: 1    Replicas: 1,2,3
Partition: 1    Leader: 2    Replicas: 2,3,1
Partition: 2    Leader: 3    Replicas: 3,1,2
```

✅ **Start producer**:

* **Key term:** Producer
* **Important rule:** The producer publishes messages to a Kafka topic.
* **Example:** Send messages to `test-topic`.

```sh
Run:
cd C:\kafka\bin\windows
kafka-console-producer.bat --topic my-topic --bootstrap-server localhost:9092
```
Type some messages and press **Enter**.


Enter payload:
```text
Hello Kafka
Message 1
Message 2
Message 3
```

✅ **Test consumer**:

* **Key term:** Consumer
* **Important rule:** `--from-beginning` tells the consumer to read available messages from the beginning.
* **Example:** Consume messages from `test-topic`.

Open another CMD window:


```sh
cd C:\kafka\bin\windows
kafka-console-consumer.bat --topic my-topic --from-beginning --bootstrap-server localhost:9092
```
- `--property print.key=true` : This option ensures that the key of the messages is printed in addition to the value.
```sh
kafka-console-consumer.bat --topic product-created-events-topic --bootstrap-server localhost:9092 --property print.key=true
```

You should see:
```text
Hello Kafka
Message 1
Message 2
Message 3
```

> ⚠️ **Important:** Do not change the `controller.quorum.voters` value between servers.
All three servers must use:
```text
controller.quorum.voters=1@localhost:9093,2@localhost:9095,3@localhost:9097
```
